# Git Utilities 
Scripts to simplify Git version control.

| Script             | Purpose                                         | Usage            |
|:------------------|:-----------------------------------------------|:----------------|
| 1. `0-current_branch`   | Displays the name of the branch you are currently on | `0-current_branch` |
| 2. `1-gpull`            | Pulls changes from origin. Defaults to 'develop' if no branch is named. | ` 1-gpull [branch_name] ` |
